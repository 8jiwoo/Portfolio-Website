# Portfolio-Website

My hand-drawn living room as a 360° space you can look around. This repo holds two versions of it.

## 1. Full portfolio

- **Link:** https://8jiwoo.github.io/Portfolio-Website/
- **File:** `index.html`

Everything is clickable: Projects, Experience, Education, Certs, Awards, Volunteering, Artworks and Contact, plus the lights, the speaker and the globe.

## 2. Contact only

- **Link:** https://8jiwoo.github.io/Portfolio-Website/contact.html
- **File:** `contact.html`

The same room, but only the lights and the Contact section respond. Everything else is scenery.

## Shared files

Both versions use the same code and artwork, so a change shows up in both.

| File | What it holds |
|---|---|
| `content.js` | All the text, links and pictures shown in the panels |
| `app.js` | The room, camera, sounds and menu |
| `style.css` | Layout and styling |
| `assets/` | The panorama, photos, certificates and sounds |
